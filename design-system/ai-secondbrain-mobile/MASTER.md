# AI SecondBrain Mobile 设计系统

> 适用于 uni-app 的 App、H5 与微信小程序。页面级规则如存在，优先读取 `pages/<page-name>.md`。

## 设计方向

- 风格：墨色知识编辑器（Editorial Knowledge Workspace）
- 设计差异度：6/10；动效强度：4/10；视觉密度：5/10
- 关键词：清醒、可信、安静、内容优先、轻量 AI 感
- 禁止：蓝紫渐变、黄褐色大面积铺底、重复等宽卡片、装饰性无限动画、Emoji 功能图标

## 颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| Primary | `#174A45` | 主操作、当前状态、关键图标 |
| Primary Dark | `#0F3430` | 深色表面和高对比文字 |
| Primary Soft | `#2F756C` | 次级强调、数据状态 |
| Accent | `#C9793F` | 单屏唯一重点、提醒，不超过页面面积 10% |
| Page | `#F3F6F5` | 页面背景 |
| Surface | `#FFFFFF` | 内容表面、底部面板 |
| Input | `#EDF2F0` | 输入与轻状态背景 |
| Text | `#162320` | 主文字 |
| Text Secondary | `#66736F` | 次级信息 |
| Border | `#E4EBE8` | 分隔线和弱边界 |
| Danger | `#B8443A` | 删除和错误状态 |

正文与背景对比度必须达到 WCAG AA。功能状态不能只通过颜色表达，需同时提供文字或图标。

## 排版与布局

- 中文使用系统无衬线字体：`PingFang SC`、`Noto Sans SC`、`system-ui`。
- 页面标题 46rpx/700，区块标题 34rpx/700，正文 28rpx/400，辅助说明不小于 24rpx。
- 页面水平边距以 32rpx 为基准；相关元素间距 8–16rpx，区块间距 36–56rpx。
- 主页面使用自定义导航并遵守 `--status-bar-height`；固定元素必须预留安全区。
- 内容列表优先采用编辑式分隔和留白，只有需要表达独立对象时才使用卡片。

## 组件规则

### 顶部栏

- 使用小型品牌眉题、明确页面标题、可访问的工作区入口。
- 操作按钮至少 80rpx 视觉区域，实际触控区域不小于 88rpx。
- 主 Tab 不叠加微信原生标题栏与自定义页头。

### 工作区切换

- 使用底部单选面板，明确显示“当前”和“切换中”。
- 切换期间锁定所有选项，防止重复请求；成功后再关闭面板并刷新页面数据。
- 当前选择需要跨重启持久化，退出登录和 401 时必须清理。
- 工作区 ID 统一按字符串语义比较，避免 Java Long 在不同端序列化造成选中态错误。

### 操作与反馈

- 所有点击操作在 100ms 内产生按压反馈。
- 网络操作超过 300ms 显示进度；提交期间禁用重复操作。
- 微交互控制在 150–300ms，并支持 `prefers-reduced-motion`。
- 图标统一通过 `AppIcon`，同层级保持一致的线性风格。

## 验收清单

- [ ] 375px 小屏和横屏无横向滚动
- [ ] 顶栏、底部导航、抽屉均避开系统安全区
- [ ] 所有关键触控目标至少 44px
- [ ] 工作区切换成功后标题、数据和下次启动状态一致
- [ ] 快速重复点击只发送一次切换请求
- [ ] 文字、边框、禁用态在亮色主题下清晰可辨
- [ ] 微信小程序、H5 和 App 构建均通过
