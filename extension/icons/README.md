# 图标设计说明

## 设计概念

**神经网络 / 知识图谱** — 5 个白色节点通过连线相互连接，中心节点更大，象征知识的核心与关联。

## 颜色方案

- 主色：`#10B981`（翡翠绿 — 代表知识生长）
- 辅色：`#0EA5E9`（天蓝 — 代表科技与连接）
- 背景：透明 PNG，渐变填充圆角方形

## 图标文件

| 文件 | 尺寸 | 用途 |
|------|------|------|
| icon16.png | 16×16 | 浏览器工具栏 |
| icon48.png | 48×48 | 扩展管理页面 |
| icon128.png | 128×128 | Chrome Web Store |
| icon.svg | 128×128 | 矢量源文件 |

## 注意事项

1. PNG 背景透明
2. 小尺寸下节点仍清晰可见
3. 深色和浅色背景下均可识别
