# 考研错题与疑问档案开发记录

> 对应需求：[考研错题与疑问归档 PRD](prd-exam-wrong-question-and-doubt-archive.md)
> 状态：核心功能已落地；错题新增可选视觉 AI 精准识别，真实图片质量仍待验收
> 更新时间：2026-10-05

## 已实现范围

- 服务端新增错题、手动复盘日志、疑问及理解修订四类数据表和对应实体、Mapper、DTO、Service、Controller。
- 所有档案及图片按 JWT 用户 ID 隔离；创建时的工作区仅作为来源上下文，不改变个人私有可见范围。
- 图片限制为 10 MB，并支持 JPG、PNG、WEBP、HEIC；Android 先建立 Room 本机草稿，再上传图片和保存档案。
- Android 可拍照、从相册选择或仅输入文字创建疑问；错题 OCR 文本、用户答案、正确答案、解析、来源、知识点和错误类型均可编辑。
- AI 可基于 OCR 文本提供科目、章节、知识点和错误类型建议；结果进入可编辑表单，失败时仍可手动保存。
- 错题支持原图复盘、显示/隐藏文字与答案解析、记录复盘结果和备注、修改元信息、标记掌握、搜索和手动排期。
- 错题排期默认空；仅主动安排后才出现在学习档案“今日待处理”。复盘后清除当前排期，不根据答对或答错自动排下一次。
- 疑问支持来源编辑、手动排期、追加“初步理解/待验证/已确认”历史、AI 参考解释及有用/无用反馈、标记解决与重新打开。
- Android 本地数据库从版本 1 迁移到版本 2，新增本机学习档案草稿表。

## 数据库部署

首次运行后端前，在应用所连接的 MySQL 数据库中执行 `sql/V15__add_exam_study_archives.sql`。该脚本只新建错题和疑问相关表，没有修改已有表。图片默认保存到服务端 `uploads/study/{userId}`，可通过 `study-archive.storage-path` 调整根目录；部署时需要将该目录纳入持久化备份。

## 当前限制

- 错题/疑问作为独立个人学习档案展示在“学习记录”页的“今日待处理”标签中；目前没有并入既有普通知识卡片的复习会话。
- AI 分类使用现有 AI 服务处理设备 OCR 文本，不对原图做服务端 OCR；公式识别质量取决于设备端 OCR，原图始终保留供用户核对。
- 错题照片继续默认设备端 OCR；配置个人视觉模型和 API Key 后，用户可主动点击“视觉 AI 精准识别”，后端才转发原图。视觉结果填入可编辑表单，缺少 Key 时保留 OCR 与手工归档路径。
- 当前接口按完整列表加载，再由 Android 端搜索；大规模数据需要分页时再补服务端分页。
