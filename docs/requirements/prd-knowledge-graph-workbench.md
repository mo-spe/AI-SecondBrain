# Web 知识网络图工作台 PRD

> 版本：V1.0  
> 日期：2026-09-03  
> 状态：已实现，待联调验收

## 目标

把原“知识体系”页内嵌、带示例数据的图谱替换为独立的探索工作台，让用户在真实知识点关系中浏览、缩放、筛选并进入知识详情。

## 已实现范围

- 新增前端路由 `/knowledge-graph`，并从“知识体系”提供全屏图谱入口。
- 仅复用 `GET /knowledge/relation/graph`；未修改后端 API、数据库表或关系数据。
- 使用 ECharts force graph 展示真实 `nodes` 与 `edges`：节点大小映射重要度，节点颜色映射掌握度，边宽映射关系强度。
- 深色沉浸画布、低对比网格、受控标签密度、缩放、平移、临时拖拽布局、本地搜索、掌握度筛选、适配和重置。
- 节点点击聚焦一跳邻接关系；详情检查器展示重要度、掌握度、关联节点，并跳转既有 `/knowledge/:id`。
- 宽屏使用右侧检查器，窄屏使用不压缩画布的侧边抽屉。
- 覆盖加载、真实空数据、筛选无结果、接口错误与重试；请求失败绝不展示模拟节点。
- 工具栏和检查器具备键盘焦点、ARIA 标签、图表 ARIA 摘要和状态播报。

## 非目标

- 不创建、编辑或删除知识关系。
- 不自动生成关系，不持久化节点布局。
- 不涉及 APK、小程序或任何后端改造。

## 接口与数据约定

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/knowledge/relation/graph` | 读取当前上下文中可见的 `nodes[]` 和 `edges[]` |

节点至少使用 `id`、`label`、`importance`、`masteryLevel`，可选 `size`、`color`；边使用 `source`、`target`、`label`、`strength`。前端会过滤无效 ID 和指向不存在节点的边，避免图谱渲染异常。
