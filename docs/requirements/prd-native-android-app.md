# AI-SecondBrain 原生 Android 应用

## 状态

进行中，首个交付是独立的 Kotlin / Jetpack Compose 工程，位于 `android/`。它与现有 uni-app 共用后端、账号和工作区数据，但不共用 UI 代码。

## 已确认范围

- Android 8.0+，Material 3、固定墨绿/纸张白/铜棕品牌主题，提供独立深色方案。
- 底部四栏：今日、知识、社区、我的；全局采集入口。
- 登录、工作区、知识、RAG、复习、广场、问答、社区资料与成长数据只读取和写入既有服务端 API，不制造演示数据。
- 采集使用本地 CameraX / 相册与 ML Kit 中文、拉丁 OCR。只有用户编辑、选择工作区并确认后，才调用 `POST /knowledge`；图片不会自动上传或自动入库。
- 本地仅保留可恢复草稿、最近知识摘要和未提交复习答案。当前登录态保存在 DataStore；客户端不保存用户 API Key。发布前应将令牌迁移至 Android Keystore 包装的安全存储。

## 2026-09-05 移动端缺陷修复与体验调整

### 背景和范围

用户提供的五张截图来自 `android/` 原生 Compose 客户端，而非 `mobile/` 中的 uni-app。本轮修改复用既有后端接口，不修改数据库、Java 服务和 Web 客户端。Android 目录在开始任务时已整体处于 Git 未跟踪状态；本轮在现有实现上修改，未覆盖其他文档或工作区改动。

### 缺陷与实现

| 问题 | 根因 | 本轮实现 |
| --- | --- | --- |
| 知识详情无法点击 | 列表未传入点击回调，Card 进入禁用状态 | 知识行接入详情导航和 `GET /knowledge/{id}`；展示标题、摘要、正文、加载、失败重试与返回 |
| 知识列表发灰、标题截断 | 禁用卡片配色与固定宽度计算，标题只显示一行 | 正常内容表面、弹性文字区域、两行标题与省略号；统计注明“已加载”，不把分页数量写成全库总数 |
| 分享页只有推荐语、两排大按钮 | 未读取 `knowledgeNodes`，非滚动 Column，操作不更新详情 | 作者和时间、推荐语、关联正文、评论分层；可滚动阅读；点赞/收藏根据服务返回的 Boolean 更新数量和状态，重复点击锁定、失败反馈 |
| 复习提前泄露答案 | `question::substring` 单参数截取了答案标记之后的文本 | 独立题干解析器截取答案标记之前的部分；兼容中英文选项符号、多行选项，不把解析中的 A/B 当成选项 |
| 复习提交后直接跳题 | ViewModel 成功后立即增加 position | 选择/输入 → 提交 → 对错、正确答案与解析 → 用户点击下一题；失败保留输入；重复提交保护；记录实际答题秒数 |
| 只有解析的异常题卡 | 原逻辑把空题干回退为原始答案 | 不展示原始答案；提示缺少题干，允许本地跳过，不发送错误答题记录 |
| 工作区切换没有反馈或页面仍显示旧内容 | 仅保存 token；已存在的 ViewModel 不观察会话变化 | 原子保存 token 与空间 ID；知识、今日复习观察会话变化并取消旧读取；界面显示当前空间、切换中、成功或失败；失败保留旧空间 |
| 无工作区时个人入口消失 | 空列表状态隐藏了整个个人页内容 | 学习管理与个人空间始终展示，协作列表独立显示加载、空状态和失败重试 |
| 空社区无法切换标签 | 标签栏放在成功列表内容内部 | 标签栏独立于列表加载状态，两栏使用弹性宽度 |
| 二级页顶部侵入状态栏、背景泛紫 | 无统一安全区和背景 Surface | 登录后的根表面应用安全区和品牌背景，阅读/复习页使用固定 TopAppBar，接入系统返回 |

### 视觉约定

沿用现有移动端“内容优先”的设计方向：墨绿色强调，灰白页面底色，白色内容表面。列表圆角收紧到 14dp，减少阴影和整块浅绿背景。标题、正文、辅助信息分别使用主题排版层级；中文跟随系统字体。新阅读页支持正文选择复制、基础 Markdown 标题与代码块，代码不执行 HTML/脚本；完整 Markdown 图片、表格和公式渲染尚未实现。

## 2026-09-05 问答社区切换闪退修复

### 原因

手机崩溃日志在 16:04 和 16:05 记录到 `ClassCastException: SquarePost cannot be cast to CommunityQuestion`，堆栈位于 `CommunityScreen` 的 LazyColumn 条目 key 索引回调。原界面将广场和问答状态合并为一个泛型列表，延迟执行的列表回调再次读取可变标签状态，并对旧列表做未经检查的强制转换，切换标签时发生类型错配。

### 修改

- 两个标签分别传入明确类型的 `ContentScreen`，移除 `UNCHECKED_CAST` 与列表强制转换。
- 每轮组合固定标签快照，使用 Compose `key` 隔离两个列表的状态，避免沿用另一种列表的条目索引。
- 条目 key 增加 `post-` / `question-` 前缀，区分可能拥有相同数值 ID 的分享和问题。
- 抽出可直接测试的 `CommunityContent`，不改动既有接口和业务数据。
- 新增界面回归用例：两个非空列表且 ID 相同时往返切换 10 次并打开条目；问答加载中、空列表、失败与重试恢复时仍可切换标签。

### 验证

- Debug APK 与 Android 界面测试包构建通过；14 项 JVM 单元测试全部通过；Lint 0 errors，保留 2 项既有 warnings。
- 修复版已通过 `install -r` 更新到连接的手机，保留应用数据。
- 用户要求继续后，在手机实际应用中完成只读浏览验证：社区进入成功；问答问题列表正常显示；知识广场与问答社区连续往返切换 5 轮，每次均显示对应列表。
- 现有问题详情打开成功，系统返回后回到社区页面；全程进程 PID 为 32371，没有发生进程重启，该进程的 AndroidRuntime 崩溃日志为空。
- 上述验证未发布回答、点赞或修改知识。新增的非空同 ID 列表与加载/空/失败状态界面用例已编译，但独立测试包仍未安装执行；不把编译成功等同于这些模拟场景全部通过。
- 过程中曾因自动审批服务提示额度不足中断；用户要求继续后审批恢复，已完成本次真实手机浏览回归。


## 2026-09-05 Android 体验重设计与问答闭环

本轮范围：原生 Android 应用。优先修复回答提交、详情返回状态、空响应处理与知识列表检索，再统一视觉和阅读层级。

### 设计决策（实现前）

参考 Notion 的 [移动工作区入口](https://www.notion.com/help/workspaces-on-mobile)、Readwise 的 [专注阅读](https://docs.readwise.io/reader/guides/workflows/longform-reading)、Google 的 [Material 层级研究](https://design.google/library/expressive-material-design-google-research)。采用它们的导航与内容优先原则，不复制品牌资产。

色彩：正文 #182039，主操作 #395BCE，背景 #F7F8FC，阅读面 #FFFFFF，次级文字 #65708B，浅色强调 #D6E3FF。错误与答题反馈使用独立语义颜色。系统无衬线适配中文与系统字体缩放；页面标题 26sp，条目标题 17sp，正文 16sp/26sp，元信息 12sp。

布局从“大口号 + 重复圆角块 + 全局加号”改为紧凑工作区工具栏、可搜索的知识目录、具备作者与回答数的社区列表、可选择正文的阅读页。招牌元素是学习页的蓝色复习入口与目录式列表，学习任务成为视觉重点。圆角只用于分组和操作面；内容本身靠间距与分隔线建立层级。

```text
原：大标题 / 口号 / 大摘要卡 / 同形卡片 / 悬浮加号
新：空间切换                知识采集
    页面标题                刷新
    搜索或社区标签
    内容标题与摘要
    作者 / 回答数 / 阅读入口
    ────────────────────
    固定四项导航
阅读：返回 / 内容类别 → 作者 → 标题 → 正文 → 轻量操作 → 讨论
问答：问题 → 回答列表 → 编辑区 → 提交状态 / 原地显示新回答
```

避免把全部页面套进同一种大卡片，也不引入无业务含义的装饰图和假统计。功能测试使用隔离接口，不向真实社区发布测试消息。


### 本轮实现

- 问答发布：纠正接口返回类型为 `CommunityAnswer`；新增独立问题状态管理，发布期间禁止重复提交，失败保留草稿，成功使用服务端返回的回答原地显示；重新进入读取服务端详情。严格按 10–10000 字校验，错误和成功均可见，不再点击发布后立即退出。
- 社区导航：保存主标签与列表状态，详情返回仍停留在原社区标签；全屏目的地保存 ID，配置变化后可恢复阅读入口。社区提供显式刷新入口。
- 实机发现的分享闪退：同一个列表中的关联知识和评论原来都使用数值 ID，两者 ID 相同时崩溃；改为 `shared-node-` 与 `comment-` 两类独立 key，回归样本刻意使用相同 ID。
- 知识：增加关键词搜索、清除、真实总数、继续加载与分页重试；切换会话取消旧请求，避免前一个空间的数据回写。
- 复习：点击今日卡片从该卡片开始，保留“选择/输入 → 提交 → 解析 → 下一题”的阶段；页面重新组合不会重载并清空答案。
- 工作区：所有主页面顶部提供当前空间及切换面板，个人空间和协作工作区均显示选中状态、切换进度与结果。凭证保存后再刷新知识与复习。
- 阅读与视觉：统一蓝灰浅色/深色配色，压缩主页面标题和摘要区域，移除遮挡内容的全局悬浮按钮，把采集放入工具栏；分享增加作者与讨论元信息，正文、代码块、互动和讨论分层；阅读页可切换大字号。
- 采集：编辑区支持滚动和键盘避让；空内容不可保存；保存时拦截重复提交，失败提示在编辑区可见；识别期间禁用重复选择图片/相机操作。
- 提醒取消：空成功响应只校验业务状态，避免服务端已经取消、本地仍误判失败。
