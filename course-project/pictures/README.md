# 课程版 UI 设计稿

本目录是课程版前端的第一轮高保真 UI 方案，不包含前端代码改动，供审核视觉方向和信息架构。

## 文件说明

- `feynman-course-ui-desktop-board.png`：桌面端设计板，包含学习概览、我的知识、费曼复述、智能测验四个核心页面。
- `feynman-course-ui-mobile-board.png`：移动端设计板，展示四个核心页面在窄屏下的顶部身份栏、内容布局和底部主导航。
- 同名 `.svg`：可放大查看的矢量版本，适合检查间距、颜色、文字层级和组件细节。

## 本轮设计方向

- 主色使用深青绿，表达稳定、专注和长期学习；薄荷绿用于主要行动和成功状态，琥珀色用于复述/待处理提示。
- 桌面端采用“学习 / 探索”分组侧栏，避免八个功能平铺后缺少层次。
- 移动端只保留五项高频导航：学习概览、我的知识、费曼复述、智能测验、知识问答；知识图谱、知识宇宙、数字地球作为探索入口保留在桌面端和后续更多菜单中。
- Dashboard 首屏只回答三个问题：我现在有什么、今天该做什么、接下来如何继续。
- 费曼复述页面将“选择知识点”和“开始讲述”拆成两个明显区域，减少用户进入页面后的决策成本。
- 智能测验页面突出题目上下文、进度和选项状态，AI 反馈放在提交后展示，避免答题过程被干扰。

## 请重点审核

1. 深青绿 + 薄荷绿 + 琥珀色的整体气质是否符合课程项目定位。
2. 桌面端侧栏分组是否合理，哪些入口应该移动到“更多”或设置中。
3. Dashboard 的信息密度是否足够，是否需要增加学习趋势、连续学习天数等信息。
4. 移动端底部导航是否保留当前五项，或把“知识问答”替换成其他高频功能。
5. 费曼复述和智能测验的核心操作是否足够突出。

确认方向后，再按这套稿件继续细化组件状态、交互反馈和前端实现。
