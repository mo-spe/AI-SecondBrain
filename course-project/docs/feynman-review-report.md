# 费曼复述功能检测报告

检测日期：2026-09-18

## 结论

费曼复述页面的前端主流程可以完成：选择知识点、开始录音、停止录音、上传音频、获得转录文本、AI 评价和保存记录。

## 本次修复状态

2026-09-18 已修复以下问题：

- 录音期间锁定知识点选择，避免录音与知识点归属错位。
- 组件卸载、路由切换、停止录音和录音异常时释放 recorder 与麦克风音频轨道。
- 前端保存成功后禁用按钮，服务端增加 `clientAttemptId` 及唯一索引，防止重复请求创建多条记录。

真实语音转文字已按课程第七次课要求接入百度智能云短语音识别；首次联调前仍需在服务端 `.env` 填写百度云凭证。

当前不建议在未配置凭证时宣称已完成真实云识别；配置完成后，原先的录音归属、资源释放和重复保存问题已经修复。下方 Major 1—4 保留为历史检测记录，已修复项已明确标注。

## 发现的问题

### Major 1：转录接口曾经没有真正识别音频（已修复）

位置：`server/src/routes/feynman.routes.js:22-29`

原实现只接收音频文件，并在没有预置文本时拼接知识点内容返回 `provider: mock`。现在服务端使用百度语音识别 SDK，接收浏览器转换后的单声道 16kHz WAV，并返回 `provider: baidu-asr`；未配置凭证时明确返回 503，而不是伪造转录结果。

影响：用户录音内容与页面展示的复述文本可能完全无关，后续 AI 评价实际上评价的是知识点原文，而不是用户的真实讲述。

### Major 2：录音时可以切换知识点，导致录音归属错位

位置：`web/src/pages/FeynmanPage.jsx:133`

知识点下拉框在录音中仍然可操作。切换时只调用 `reset()`，没有停止当前录音；停止后，录音文件会使用新选择的 `selectedId` 上传。

浏览器检测证据：录音从“向量数据库”开始，切换到“费曼学习法”后仍显示“正在聆听…”，最终请求使用 `knowledgeId: knowledge-2`。

### Major 3：离开页面时没有释放麦克风

位置：`web/src/pages/FeynmanPage.jsx:26-28, 40-48`

麦克风流只在 `MediaRecorder.onstop` 中调用 `track.stop()`。组件卸载时的清理只释放音频 Blob URL，没有停止正在录制的 recorder 或 stream。

浏览器检测证据：开始录音后跳转到“我的知识”，记录到的 `tracks_stopped_after_navigation` 为 `0`。

影响：用户离开页面后浏览器可能仍保持麦克风占用，属于隐私和资源释放风险。

### Major 4：保存操作可以重复提交

位置：`web/src/pages/FeynmanPage.jsx:99-114, 140`

保存成功后 evaluation 仍然保留，保存按钮仍然可点击，没有 `saved` 状态或幂等保护。

浏览器检测证据：连续点击两次“保存这次复述”，前端产生了 2 个 `POST /api/feynman/attempts` 请求。

影响：MongoDB 中会产生重复的复述记录，知识点的最近掌握度也会被重复更新。

### Minor 1：非法音频格式会被当成 500 错误

位置：`server/src/routes/feynman.routes.js:14-16`、`server/src/middleware/error.js:5-7`

Multer 的文件过滤器直接抛出普通 Error，错误没有明确的 4xx 状态码，因此会被统一处理成 500。用户上传不支持的音频格式时，页面会得到“服务器错误”语义，而不是明确的输入提示。

### Minor 2：AI JSON 模式对 OpenAI-compatible Provider 兼容性不足

位置：`server/src/services/ai.service.js:39-45`

费曼评价会统一发送 `response_format: { type: 'json_object' }`。部分 OpenAI-compatible 服务或模型不支持该参数，或者仍返回带包裹文本的内容，可能触发“AI Provider 返回格式不是有效 JSON”。当前解析器已有代码块和大括号兜底，但不能解决 Provider 拒绝参数的情况。

### Minor 3：AI 返回的 polishedText 没有展示

服务端会生成并保存 `polishedText`，但页面只展示评分、评价、优点和下一次建议，没有展示“更清晰的复述”。这不是流程阻断问题，但会使 AI 反馈的一部分价值没有被用户看到。

## 已验证通过的部分

- 页面可以加载知识点列表。
- 没有知识点时能显示引导空状态。
- 录音按钮、停止录音按钮状态切换正常。
- 音频上传请求包含 `knowledgeId` 和 `audio` 文件。
- 评价请求包含 `knowledgeId` 和 `transcript`。
- 评价结果可以展示评分、评价、优点和改进建议。
- 保存请求能够发送并显示成功提示。
- 前端构建之前已通过 `npm run build`。

## 建议修复顺序

1. 已修复录音生命周期：录音期间锁定知识点选择；组件卸载、路由切换和异常时停止 recorder 与所有 audio tracks。
2. 已增加保存后的状态与幂等保护，避免重复创建 attempt。
3. 已接入百度真实语音转文字 Provider；服务端凭证配置和真实云响应仍需按本文档完成一次联调。
4. 已统一处理不支持的音频格式；AI JSON mode 兼容性仍需根据实际 Provider 决定是否进一步调整。
5. 后续可在评价结果中增加 polishedText 展示，并补充针对 Provider 超时和百度云错误码的自动化测试。

本次使用静态代码审查和本地浏览器自动化完成了前端流程及边界行为验证。浏览器阶段对 API 使用了受控 mock，以便稳定验证页面状态流转；没有在本次检测中消耗真实 AI Provider 请求，也没有写入 MongoDB 生产数据。
