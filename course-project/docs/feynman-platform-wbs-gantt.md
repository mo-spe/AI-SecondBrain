# 费曼学习平台WBS工作分解与甘特图

编制日期：2026年11月11日

## 一 项目目标与计划假设

本项目建设一个费曼学习平台，支持用户注册登录、知识点管理、录音转文字、AI润色与评分、智能测验、个人知识库问答、知识可视化以及桌面与云端交付，帮助学习者通过主动复述发现并修正理解中的不足。

本练习假设团队由4名成员组成，周期为8周，每周安排2次课程，每次4学时，对应16次课程、64个课堂学时。开发、测试与课外协作并行开展，课堂学时不等同于项目总人时。以下为课程练习的假定计划，不表示现有项目的实际开工日期或当前完成进度。

技术方案采用React、Vite、Express和MongoDB Atlas；语音识别使用百度接口，AI润色与评价使用服务端模型接口；三维展示采用Three.js与CesiumJS，桌面端使用Electron。

## 七 里程碑与风险控制

| 里程碑 | 时间 | 完成标准 |
| --- | --- | --- |
| M1 基础接口可用 | 第2周末 | 数据库、认证、知识API和前端骨架联通 |
| M2 复述闭环可用 | 第5周末 | 知识、录音转录、润色评价与状态保存可演示 |
| M3 学习与可视化功能集成 | 第7周末 | 测验、RAG、图谱及三维场景集成，发布环境就绪 |
| M4 最终验收与提交 | 第8周末 | 测试通过，桌面安装包、云端地址及文档交付 |

语音和模型额度、网络或配置可能阻塞4.1和4.2，因此第1周先确认云服务账号与最小连通性。RAG、三维场景与打包可能增加调试时间，应优先保证知识管理和费曼复述闭环；扩展功能采用可演示的最小范围，不临时增加需求。各工作包在完成时交给D执行单项测试，第8周集中进行跨模块回归与缺陷修复。

结论：通过按成果分解的WBS，将需求、开发、AI能力、可视化和交付分别落实到负责人；通过并行排期，将整体工期控制在假定的8周内，并以阶段里程碑和验收清单检查交付情况。
